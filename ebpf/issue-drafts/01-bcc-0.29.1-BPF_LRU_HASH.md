# タイトル案
Ubuntu 24.04 の BCC 0.29.1 で `BPF_LRU_HASH` がコンパイルエラーになる（報告）

# 本文

はじめまして。PyCon JP 2026 の LT を拝見して、このツールを試させていただきました。

先にお断りしておくと、私は OS や C 言語、eBPF についての知見がほとんどありません。以下の切り分けや回避策は、
Claude Code（AI）に手伝ってもらいながら進めたもので、私自身が中身を十分に理解できているわけではありません。
的外れな内容や、そもそも私の環境側の問題である可能性もあると思いますので、その場合はご指摘いただければ幸いです。

## 起きたこと

README の Ubuntu 向け手順（`apt install bpfcc-tools python3-bpfcc linux-headers-$(uname -r)`）で BCC を入れて実行したところ、
BPF プログラムのコンパイルで失敗しました。

## 環境

- Ubuntu 24.04.4 LTS、kernel 6.8.0-117-generic
- BCC: `bpfcc-tools` / `python3-bpfcc` 0.29.1+ds-1ubuntu7（Ubuntu 標準パッケージ）
- blocking-io-check 0.2.0（main、コミット 0f53fc2 時点）
- x86_64 と arm64（aarch64）の両方で同じエラーになりました

## 再現手順

```bash
git clone https://github.com/ryuichi1208/blocking-io-check-py && cd blocking-io-check-py
uv venv --system-site-packages && uv sync
sudo .venv/bin/blocking-io-check -p nomatch -d 2
```

## 試したこと

同じ BCC で、マップ定義だけの最小プログラムを試したところ、次のような結果になりました（AI に手順を教えてもらいながら実行したものです）。

| 書き方 | BCC 0.29.1 での結果 |
|---|---|
| `BPF_LRU_HASH(m, struct key_t, u8, 1024)` | 失敗 |
| `BPF_LRU_HASH(m, struct key_t, u8)` | 失敗 |
| `BPF_HASH(m, struct key_t, u8, 1024)` | 成功 |
| `BPF_TABLE("lru_hash", struct key_t, u8, m, 65536)` | 成功 |

そこで `trace.bpf.c` の該当 3 行を次のように書き換えたところ、この箇所のコンパイルは通るようになりました。

```c
BPF_TABLE("lru_hash", struct key_t, u8, fd_nonblock, 65536);
BPF_TABLE("lru_hash", struct key_t, u8, fd_epoll, 65536);
BPF_TABLE("lru_hash", struct key_t, struct peer_t, peer_map, 65536);
```

これが正しい直し方なのか、BCC のバージョン差による一時的な問題なのかは、私には判断がつきません。
README の Ubuntu 手順で入る BCC がこの版だったので、同じところで詰まる方がいるかもしれないと思い、報告だけさせていただきます。
